# Стадия infra_tests

После bugbot и до security verify сам поднимает или усыновляет disposable PostgreSQL и гоняет только infra-tier, задействованный в change.

Детерминированный слой выбирает набор, определяет среду, стартует или усыновляет БД, запускает pytest и классифицирует падения по таблице сигнатур. Модель вызывается только если сигнатура неизвестна: среда, triage теста, ремонт harness, запись runbook.

Нельзя ослаблять assertions, снимать маркеры, править `tests/db_guard.py` без отдельного разрешения и убивать чужой процесс на порту. Секреты из URL в журнал не писать. Если среда не поднялась, итог `BLOCKED_ENV` с исключением, security не начинается.
