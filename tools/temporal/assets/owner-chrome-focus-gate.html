Кликни окно Chrome с игрой, затем напиши GO в чате

Smoke-проверка требует, чтобы вкладка игры была видимой (не hidden).

URL игры (скопируйте в Chrome):

http://127.0.0.1:8080/novel/null-parallele/play
  1. Переключись на Chrome с игрой по URL выше.
  2. Убедись, что окно на переднем плане.
  3. Вернись в Cursor и напиши GO — агент запустит браузерную проверку.

Пока не напишете GO в чате — smoke не запустится. Это не финал pipeline.
